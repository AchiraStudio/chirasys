# Kivo UI Overhaul — "Dashdark X" Direction

Restyle the entire app (all pages, modals, drawers, sidebar, topbar) into one cohesive design system modeled on the reference image — with **both dark and light themes fully working**. No business-logic changes; presentation only, plus the agreed functional polish (toasts, unified confirm, fixed animations, emoji→icons).

## 1. Design tokens (the foundation — `src/index.css`)

Replace the current 6 indigo tokens with a **dual-theme CSS variable system** (Tailwind v4 `@theme inline` + `:root` / `.dark` overrides) so utilities like `bg-card`, `border-line`, `text-heading`, `bg-primary` auto-switch with the `.dark` class — eliminating hand-written `dark:` pairs for surfaces.

**Dark (from reference):** canvas `#081028`, sidebar/card `#0B1739`, muted fill/input `#111C44`, hairline line `#1E2A4A`, headings `#FFFFFF`, body `#A3B1D6`, muted `#6B7A99`, primary magenta `#CB3CFF` (hover `#B428F0`), accent cyan `#00C2FF`, plus status tones (success/warning/danger adapted to navy).

**Light (designed counterpart):** canvas `#F4F6FB`, card `#FFFFFF`, muted fill `#F1F3FA`, hairline `#E3E7F2`, headings `#171C3A`, body `#5A6584`, muted `#8A94B0`, primary darkened magenta `~#9B1FD8` (WCAG-safe with white text), accent darkened cyan `~#0090C8`.

Also: radius rules (cards/tables `rounded-xl`, buttons/inputs `rounded-lg`, pills `rounded-full`, modals `rounded-2xl`), border-first elevation (shadows only on overlays), real keyframe animations (`fade-in`, `pop-in`, `slide-in-right`) replacing the dead `animate-in` classes, retinted scrollbar/`select`/`option` styles, keep print + fast-render CSS untouched. Delete dead code: `tailwind.config.js`, `--color-sidebar*` tokens, `.glass`/`.glass-card`.

**Font:** bundle `@fontsource-variable/manrope` (offline, no CDN), set as `--font-sans`, tabular numerals on tables.
